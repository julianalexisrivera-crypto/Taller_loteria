1 Mejora de la Interfaz

La interfaz original era funcional pero visualmente básica: fondo gris, botones verdes estándar y sin identidad visual. Se rediseñó completamente adoptando un tema de casino nocturno que refuerza la temática del juego.

Cambios aplicados en style.css y view.php

  • Importación de tipografías web: Boogaloo (display) + Nunito (cuerpo) vía Google Fonts.
  • Fondo radial degradado en tonos violeta/morado profundo con partículas doradas decorativas (radial-gradient + ::before).
  • Panel de puntaje destacado con brillo dorado (text-shadow, borde sutil).
  • Imágenes dentro de "slots" individuales con efecto hover: scale(1.05).
  • Resultado coloreado según estado: verde (Ganaste), rojo (Perdiste), dorado pulsante (Game Over).
  • Botones diferenciados: dorado sólido para Jugar, outline dorado para Guardar, morado para Reiniciar.
  • Estructura semántica HTML5 con <meta viewport> y lang="es".

Se localizaron y modificaron todos los puntos del código donde se inicializa o reinicia el puntaje:

❌ Antes — controller.php $this->puntaje = isset($_SESSION['puntaje']) ? $_SESSION['puntaje'] : 1000; // En guardar(): $_SESSION['puntaje'] = 1000;
✅ Después — controller.php $this->puntaje = isset($_SESSION['puntaje']) ? $_SESSION['puntaje'] : 2000; // En guardar(): $_SESSION['puntaje'] = 2000;
❌ Antes — view.php $puntaje = isset($_SESSION['puntaje']) ? $_SESSION['puntaje'] : 1000;
✅ Después — view.php $puntaje = isset($_SESSION['puntaje']) ? $_SESSION['puntaje'] : 2000;

4 PHP Lint — Integración Continua (CI)

¿Qué es PHP Lint?

PHP Lint es la validación de sintaxis que realiza el intérprete PHP sobre un archivo fuente sin ejecutarlo. Se invoca con php -l archivo.php. Detecta errores de parseo (paréntesis sin cerrar, etiquetas mal formadas, palabras clave mal escritas) antes de que el código llegue a producción.

En un flujo DevOps / CI-CD, ejecutar PHP Lint en cada push garantiza que ningún archivo sintácticamente roto se despliegue al servidor. Es la primera línea de defensa, rápida y sin dependencias externas.

Script lint.sh

#!/bin/bash
for f in *.php; do
    result=$(php -l "$f" 2>&1)
    if echo "$result" | grep -q "No syntax errors"; then
        echo "  ✅  $f — OK"
    else
        echo "  ❌  $f — ERROR: $result"
    fi
done

Pipeline GitHub Actions (.github/workflows/ci.yml)

jobs:
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with: { php-version: '8.2' }
      - name: PHP Lint
        run: for f in *.php; do php -l "$f"; done
      - name: Tests
        run: php test_jugar.php
